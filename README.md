# Anenji / Aninerel 4200: локальная интеграция инвертора в Home Assistant через ESPHome + Modbus

## 🌟 Описание проекта

**invertor-Anenji-Aninerel4200-esphome-local** — проект локальной интеграции инвертора Anenji / Aninerel 4200 Вт в Home Assistant **напрямую через Modbus RTU**, без облачных сервисов и штатного Wi-Fi-модуля производителя.

Инвертор подключается к ESP32-C3 по UART, 9600 бод. ESPHome опрашивает регистры Modbus и публикует данные в Home Assistant через нативный API. Всё работает **полностью локально**, без обращений к внешним серверам.

Проект позволяет:

- отслеживать состояние инвертора в реальном времени: напряжение, ток, мощность, частоту, температуру, SOC батареи;
- читать и расшифровывать коды ошибок и предупреждений в человекочитаемый текст;
- управлять режимами работы инвертора и настройками АКБ прямо из Home Assistant;
- вести учёт энергии PV и потребления из сети с ежедневным сбросом;
- использовать штатный веб-интерфейс ESPHome для диагностики.

## 🔑 Ключевые возможности

### 📊 Телеметрия в реальном времени

- **Вход (сеть):** напряжение, частота, средняя мощность.
- **Выход (инвертор):** эффективное напряжение, ток, частота, активная и полная мощность.
- **Батарея:** среднее напряжение, ток, мощность, SOC, ток заряда/разряда.
- **PV (солнце):** среднее напряжение, ток, мощность, мощность заряда от PV.
- **Инвертор:** частота, средняя мощность, мощность заряда, температура DCDC и инвертора.
- **Нагрузка:** процент загрузки, rated power.

### ⚡ Энергоучёт

- **PV energy today** — энергия от солнечных панелей за текущие сутки (сброс в полночь).
- **PV energy total** — накопленная энергия PV за всё время (не сбрасывается).
- **Grid import energy today** — потребление из сети за текущие сутки.
- **Inverter total consumption today** — общее потребление нагрузки за сутки.
- **Ручная коррекция** общего счётчика PV через отдельную настройку.

Все счётчики считаются на стороне ESPHome через `interval` с фиксированным шагом 10 секунд. Сброс дневных счётчиков — **одновременный**, по единой глобалке `energy_day` в формате `YYYYMMDD`.

### 🚨 Диагностика

- **Fault** — расшифровка 27 кодов ошибок (перегрев, перегрузка, КЗ, просадка шины и т.д.).
- **Warning** — расшифровка 19 предупреждений (низкое напряжение сети, разряд АКБ, забитый вентилятор и т.д.).
- **Operation mode** — текущий режим: Power On, Standby, Mains, Off-Grid, Bypass, Charging, Fault.
- Кнопка **Exit fault state** для сброса аварийного состояния.

### ⚙️ Управление настройками

Все ключевые параметры инвертора доступны как сущности Home Assistant:

- **Режимы работы:** Output mode, Output priority, Input voltage range, Battery type.
- **Настройки АКБ:** напряжения защиты, Bulk/CV, Float, Equalization, максимальные токи заряда.
- **SOC-пороги:** возврат к сети, возврат к батарее, Low DC cut-off.
- **Сервисные:** зуммер, подсветка LCD, энергосбережение, автоперезапуск.
- **Интервалы опроса:** отдельно для телеметрии и для настроек.

## 🛠 Компоненты и аппаратура

### Основные компоненты

- **Микроконтроллер:** ESP32-C3 (IDF-фреймворк).
- **Преобразователь интерфейса:** TTL ↔ RS485 (например, MAX485 или аналог).
- **Инвертор:** Anenji / Aninerel 4200 Вт (протокол Modbus RTU, адрес `0x01`).

### Программные зависимости

- **ESPHome:** актуальная версия с поддержкой `modbus_controller`.
- **Home Assistant:** интеграция через нативный API.
- **Компоненты ESPHome:** `uart`, `modbus`, `modbus_controller`, `template`, `total_daily_energy`.

## 📋 Установка и настройка

### 1. Подготовка оборудования

- Подключите RS485-модуль к пинам ESP32-C3: `GPIO21` (TX), `GPIO20` (RX).
- Подключите линии A/B RS485 к соответствующим контактам инвертора.
- Убедитесь, что адрес Modbus инвертора — `0x01`, а скорость — `9600`.

### 2. Настройка ESPHome

Откройте `aninerel-4200-invertor.yaml` и настройте под себя:

substitutions:
-  name: "aninerel4200"
-  friendly_name: "Aninerel4200"
-  tx_pin: GPIO21
-  rx_pin: GPIO20
-  device_ip: 192.168.0.116
-  version: "05.10.2026"
-  reboot_timeout: 0s
-  flash_write_interval: 10min
### 3. Подключаемые компоненты
- <<: !include attach/common/esphome.yaml
<<: !include attach/common/esp/esp32_c3_idf.yaml
<<: !include attach/common/logger/debug_component_error.yaml
<<: !include attach/common/api.yaml
<<: !include attach/common/ota.yaml
<<: !include attach/common/wifi.yaml
<<: !include attach/common/web/web_server3.yaml
packages:
  common: !include attach/packages/standart.yaml

### 4. Интеграция с Home Assistant

- Соберите и прошейте ESP32-C3.
- В Home Assistant устройство появится автоматически через ESPHome-интеграцию.
- Все сенсоры, `select`, `number`, `switch`, `button` и `text_sensor` будут доступны как сущности.

## 🎮 Использование

### Веб-интерфейс

- Доступ по IP-адресу устройства (компонент `web_server`).
- Просмотр всех сенсоров и логов в реальном времени.

### Home Assistant

- **Dashboard:** карточки с мощностями, напряжением, SOC и состоянием инвертора.
- **Автоматизации:** уведомления при смене режима, аварии, низком SOC.
- **Энергоучёт:** готовые сенсоры для интеграции с Energy Dashboard.

### Энергоучёт: как это работает

1. **Каждые 10 секунд** ESPHome пересчитывает приращение энергии:
   - для PV: `W × 10 / 3600 / 1000 = кВт·ч`;
   - для сети: `W × 10 / 3600 / 1000 = кВт·ч`.
2. **При смене дня** (по времени Home Assistant) оба дневных счётчика сбрасываются одновременно.
3. **Общий счётчик PV** растёт постоянно и не сбрасывается.
4. **Потребление нагрузки** считается платформой `total_daily_energy` с фильтром от отрицательных значений.

## 📊 Сенсоры и сущности

### Основные сенсоры (пример)

| Сущность | Описание |
|---|---|
| `sensor.pv_energy_today` | Энергия PV за сегодня, кВт·ч |
| `sensor.pv_energy_total` | Энергия PV за всё время, кВт·ч |
| `sensor.grid_import_energy_today` | Импорт из сети за сегодня, кВт·ч |
| `sensor.inverter_total_consumption_today` | Потребление нагрузки за сегодня, кВт·ч |
| `sensor.battery_state_of_charge` | SOC батареи, % |
| `sensor.battery_average_power` | Мощность батареи (+ заряд / − разряд), Вт |
| `sensor.pv_average_power` | Мощность PV, Вт |
| `sensor.output_active_power` | Активная мощность нагрузки, Вт |
| `sensor.average_mains_power` | Потребление из сети, Вт |
| `sensor.inverter_temperature` | Температура инвертора, °C |
| `text_sensor.fault` | Расшифровка ошибок |
| `text_sensor.warning` | Расшифровка предупреждений |
| `text_sensor.operation_mode` | Режим работы инвертора |

### Управление (пример)

| Сущность | Описание |
|---|---|
| `select.output_priority` | Приоритет источника (UTI / SOL / SBU / SUB) |
| `select.battery_type` | Тип АКБ (AGM / FLD / USER / Li1–Li4 / Lib) |
| `number.max_charging_voltage` | Напряжение Bulk/CV, В |
| `number.maximum_charging_current` | Максимальный ток заряда, А |
| `number.soc_point_back_to_utility` | SOC возврата к сети, % |
| `switch.remote_switch` | Удалённое включение/выключение |
| `button.exit_fault_state` | Сброс аварийного состояния |
